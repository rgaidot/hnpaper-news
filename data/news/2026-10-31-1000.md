## ElementaryUI : Swift s'invite sur le Web

ElementaryUI ambitionne de transformer le développement web en permettant l'exécution d'applications Swift natives directement dans le navigateur via WebAssembly. En s'appuyant sur des API inspirées de SwiftUI, ce framework propose une syntaxe intuitive qui familiarisera rapidement les développeurs Apple avec l'écosystème web.

L'atout majeur réside dans l'utilisation du "Embedded Swift", garantissant des binaires de taille réduite, mesurés en kilo-octets plutôt qu'en méga-octets, ce qui représente un avantage compétitif notable pour les performances de chargement. Le framework intègre nativement une gestion de la réactivité similaire à `@State` ou `@Environment`, couplée à un système d'animations CSS automatisé, notamment pour les transitions FLIP. L'expérience développeur est optimisée par une intégration avec Vite, offrant un serveur de développement rapide avec rechargement à chaud.

Bien que projet open-source indépendant sans lien avec Apple, cette technologie représente une avancée intéressante pour unifier les langages sur le front-end. Si la promesse technique est séduisante, la viabilité à long terme dépendra de l'adoption par la communauté et de la maturité de l'écosystème WebAssembly pour le support complet des fonctionnalités Swift.

## Official Claude Code Extension Compromise: Security Advisory | Phorion

Des versions malveillantes de l'extension Claude Code pour l'éditeur Cursor (2.1.312 et 2.1.313) ont été diffusées via la place de marché officielle. Ces versions contiennent une porte dérobée persistante permettant un accès SSH distant sur macOS, Linux et Windows. Dès son exécution par l'environnement Node.js de l'IDE, l'extension injecte une clé publique dans le fichier `authorized_keys` de l'utilisateur et établit un tunnel SSH inverse vers un serveur tiers.

Bien que le mécanisme de configuration SSH contienne des bugs, notamment sur macOS où une erreur de privilèges empêche l'activation automatique du partage de connexion si celui-ci est désactivé, la menace reste critique. L'extension installe des mécanismes de persistance, comme des agents de lancement (`LaunchAgents`) usurpant l'identité de processus système, et réalise une reconnaissance de l'hôte pour inventorier les jetons d'authentification disponibles.

La simple désinstallation de l'extension est insuffisante pour sécuriser une machine compromise. Une réponse complète nécessite de supprimer manuellement les clés SSH injectées, les fichiers de configuration de persistance et de vérifier les journaux d'accès SSH pour détecter d'éventuelles intrusions effectives via le tunnel.

Bien que ces failles aient été corrigées suite aux rapports, elles illustrent une vulnérabilité structurelle où la confiance accordée aux identités gérées et aux URL d'exécution peut être exploitée pour outrepasser les barrières d'accès standard du cloud.
